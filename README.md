# Roblox Scripts (Executor)

Collection of scripts for **Roblox executors** (Synapse, Fluxus, Wave, Solara, etc.).

> These scripts are made **for educational and testing purposes only**.  
> Using them in public games may violate the [Roblox Terms of Service](https://en.help.roblox.com/hc/en-us/articles/115004647846) and can result in account bans.  
> **You are solely responsible** for how you use them.

---

## Included Scripts

| File                 | Description                                      |
|----------------------|--------------------------------------------------|
| `aimassist_script`   | Aim Assist                                       |
| `spectator_script`   | Spectator GUI / spectator mode                   |

> The scripts are obfuscated. Use them in an executor that supports `loadstring` or by pasting the code directly.

---

## How to Use

1. Open your favorite Roblox executor.
2. Copy the content of the script you want to use.
3. Paste it into the executor and click **Execute** / **Run**.
4. If the script has a GUI, it should appear automatically.

---

## Requirements

- Up-to-date Roblox executor
- Compatible execution level (most modern executors work fine)
