# Roblox Scripts (Executor)

Colección de scripts para **ejecutores de Roblox** (Synapse, Fluxus, Wave, Solara, etc.).

> **Aviso importante**  
> Estos scripts están hechos **solo con fines educativos y de prueba**.  
> Usarlos en juegos públicos puede violar los [Términos de Servicio de Roblox](https://en.help.roblox.com/hc/en-us/articles/115004647846) y resultar en baneo de cuenta.  
> **Tú eres el único responsable** de cómo los uses.

---

## Scripts incluidos

| Archivo              | Descripción                                      |
|----------------------|--------------------------------------------------|
| `aimassist_script`   | Aim Assist (asistencia de apuntado)              |
| `spectator_script`   | GUI de espectador / spectator mode               |

> Los scripts están ofuscados. Se recomienda usarlos en un ejecutor compatible con `loadstring` o pegando el código directamente.

---

## Cómo usar

1. Abre tu ejecutor de Roblox favorito.
2. Copia el contenido del script que quieras usar.
3. Pégalo en el ejecutor y dale a **Execute** / **Run**.
4. Si el script tiene GUI, debería aparecer automáticamente.

---

## Requisitos

- Ejecutor de Roblox actualizado
- Nivel de ejecución compatible (la mayoría de ejecutores modernos sirven)
